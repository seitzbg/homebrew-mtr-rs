# homebrew-mtr-rs

Homebrew tap for [mtr-rs](https://github.com/seitzbg/mtr-rs), a Rust port of mtr (My TraceRoute).
The formula installs the prebuilt release tarballs for macOS (Apple silicon and Intel) and Linux
(x86_64 and aarch64).

    brew install seitzbg/mtr-rs/mtr-rs

`mtr-rs-packet` opens raw sockets, which need root. Homebrew cannot install a setuid binary, so
after every install or upgrade either run `sudo mtr-rs`, or make the helper start as root once
(it drops back to the invoking user as soon as its sockets are open):

    sudo chown root:wheel "$(brew --prefix)/opt/mtr-rs/bin/mtr-rs-packet"
    sudo chmod u+s "$(brew --prefix)/opt/mtr-rs/bin/mtr-rs-packet"

On Linux grant the capability instead: `sudo setcap cap_net_raw+ep "$(brew --prefix)/opt/mtr-rs/bin/mtr-rs-packet"`.

The formula is generated by `scripts/homebrew-formula.sh` in the main repository; edit it there.
